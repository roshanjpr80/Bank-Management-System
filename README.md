## Bank Management System

A professional Bank Management System developed using Python and Streamlit. This application allows users to create accounts, deposit and withdraw money, transfer funds, view account details, calculate interest, and manage banking operations through an admin panel.

# Customer Features

Create New Account
Deposit Money
Withdraw Money
Transfer Money
View Account Details
Balance Inquiry
Transaction History
Interest Calculator
Search Accounts
Secure PIN Authentication

# Admin Features

Admin Login
View All Accounts
Monitor Customer Accounts
View Total Deposits
Account Search
